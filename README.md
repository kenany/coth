# coth

Calculate the hyperbolic cotangent of a number.

## Example

``` javascript
import { coth } from 'coth';

coth(Math.PI);
// => 1.0037418731973
```

## Installation

``` bash
$ npm install coth
```

## API

``` javascript
import { coth } from 'coth';
```

### `coth(x)`

Given a _Number_ `x`, returns the hyperbolic cotangent of `x` as a _Number_.
